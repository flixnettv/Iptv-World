# IPTV World 🌍

أفضل خدمات IPTV العربية والعالمية

## 🚀 المميزات

- ✅ قنوات HD/FHD/4K
- ✅ دعم فني 24/7
- ✅ تحديثات مستمرة
- ✅ أسعار تنافسية

## 📦 التثبيت

1. Clone المشروع
```bash
git clone https://github.com/flixnettv/Iptv-World.git
```

2. اذهب للمجلد
```bash
cd Iptv-World
```

3. ارفع الملفات على Vercel

## 🔧 الإعدادات

أضف المتغيرات دي في Vercel:
- `SUPABASE_URL`
- `SUPABASE_ANON_KEY`
